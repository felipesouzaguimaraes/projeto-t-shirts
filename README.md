Este é o **Projeto T-Shirt!**, uma página modelo desenvolvida para simular a interface de uma loja virtual voltada para a venda de camisetas e artigos de moda. O site foi criado puramente com tecnologias Front-End com o objetivo de aplicar na prática técnicas de layouts comerciais, vitrines e blocos de conteúdo.

A proposta principal deste espaço foi simular um ambiente de e-commerce real, organizando categorias de produtos, tabelas de diferenciação e áreas promocionais com foco em uma experiência de navegação limpa para o usuário.

## 🎨 Funcionalidades e Organização do Modelo

A estrutura foi planejada para simular os principais componentes que uma landing page de vendas precisa ter:

| Componente / Seção | Implementação Técnica |
| :--- | :--- |
| **Menu de Navegação** | Categorias divididas de forma realista (Feminino, Masculino, Infantil, Marcas, Beleza e Ofertas) além de integração com redes sociais. |
| **Blocos Informativos** | Apresentação detalhada sobre o produto, incluindo história, evolução e uso atual das peças no cotidiano. |
| **Tags de Precificação** | Utilização de marcação semântica (`<s>` e `<strong>`) para exibir promoções de forma visualmente clara e chamativa (*De R\$ 54,90 por R\$ 49,90*). |
| **Diferenciação de Itens** | Seção técnica detalhando de forma clara as variações de modelos para auxiliar o consumidor (como a diferença entre T-Shirt, Baby Look e Camisa). |

## 🛠️ Tecnologias e Recursos Utilizados

* **HTML5:** Marcação focada na organização de seções informativas, textos promocionais e listas de características.
* **CSS3 Nativo:** Aplicação de paletas de cores harmônicas voltadas para o nicho de moda, estilização de tipografia e botões de ação.
* **Efeitos de Estilo:** Criação de destaques visuais para as chamadas de ofertas e caixas de diferenciação de produtos.

---

## 📂 Estrutura do Repositório

* `index.html` — Estrutura e conteúdo da página principal da loja virtual.
* `estilos/` (ou pasta de CSS correspondente)
  * `style.css` — Arquivo com as folhas de estilo que ditam o visual, fontes e o design das seções da página.
* `imagens/` — Banco de dados contendo os banners, ilustrações das peças de roupa e ícones institucionais.

## 🚀 Como Executar o Projeto Localmente

Por se tratar de um site estático para fins de estudo de interface, você pode executá-lo em qualquer máquina:

1. Baixe os arquivos ou clone este repositório.
2. Abra a pasta do projeto.
3. Dê um duplo clique no arquivo `index.html` para carregar o modelo de e-commerce diretamente em seu navegador.
